# 养石头：硬撑

## [🪨 点击这里，领养你的石头](https://chixu-614.github.io/pet-rock/)

**无用宠物研究所 · 第 001 号**

养一块石头。不用签到，不怕饿死，也没有离线惩罚。

它不怎么努力，但很会硬撑。

### 可以做点什么

摸摸它，给它喂饭，带它散步，或者把它转得晕头转向。

捡点小东西布置住处，戴一顶看起来很有身份的帽子，再请几位石头朋友来坐坐。偶尔听它说两句没什么用、但可能很像你的话。

不想做什么也没关系。放着就好，它不会怪你。
