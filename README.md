## 发布与打开（推荐 GitHub Pages）

纯静态多文件网页，无后端、无 API、无需 npm 构建，运行时不依赖 CDN。发布后任何人都能通过链接玩，不需要作者手机持续运行服务。

1. 如需自行部署，把工程目录里的内容上传到仓库根目录，让 index.html 位于根目录，保留子目录结构。
2. 仓库 Settings → Pages → Deploy from a branch，选择实际上传的分支（通常 main）及 / (root)，保存。
3. 等待发布完成，使用 Pages 显示的公开网址。项目采用相对路径，支持仓库子路径。Pages 可用性受账号与仓库设置影响，最简单是使用公开仓库。

本项目通过本仓库的 GitHub Pages 发布，游玩入口见本文顶部。

也可保留整个目录打开 index.html；不要单独搬走 HTML。部分 Android content:// 预览会阻止加载相邻文件，此时优先使用发布后的 Pages 链接。

开发人员可选用 Python 临时 HTTP 测试，但不属于玩家运行条件，也不作为公开交付入口。

## 操作

- 拖动画布旋转石头；轻点画布或“摸摸”按钮摸摸。
- 松手按单次累计拖动距离给出普通旋转或转晕反馈，间隔至少约 6.5 秒；弹窗期间不插话，也不消耗冷却。
- “转回来”恢复初始朝向并随机回应。
- 新版拖动不再算散步，请使用“带它散步”按钮。
- 随机物品免费抽取：小床、小毯子、小帽子、小纸箱、迷你路牌和小纸条。地面摆件同时一件，帽子单独戴，全部可收纳且不删除收藏；小纸条随时可读。重复物品不会堆积。
- 使用虚拟相机，不访问实体摄像头，不请求相机权限。

## 目录

- index.html：页面结构及脚本加载顺序。
- css/style.css：界面、排版、响应式样式。
- js/game.js：玩法接线、弹窗、成就、导入导出。
- js/dialogue.js：11 类共 99 条本地预设文案（含沿用文案），洗牌取用，一轮用完前不重复，跨轮避免紧邻重复；刷新后队列重置，无 AI 接口。
- js/store.js：存档读写与数据校验，RockStore。
- js/scene.js：Three.js 场景、程序生成石头、贴面笔画、光影、旋转与动画，RockScene。
- js/icons.js：统一内联 SVG 图标，RockIcons。
- vendor/three.min.js：本地 Three.js 0.160.1，不依赖运行时 CDN。
- vendor/THREE-LICENSE.txt：第三方库许可证。
- docs/TESTING.md：本轮验证记录和待测项。

经典脚本按 Three → icons → store → scene → dialogue → feedback → game 加载，无需 npm 或构建步骤。项目没有自动发布。

## 存档迁移

主键 pet-rock-hard-carry-v1 沿用旧版，但不同浏览器、file/content/http 来源和端口不保证共享存档。请在旧版先“导出存档”，在新版“导入存档”，确认替换。格式为 pet-rock-backup，文件名为“石头的户口本.json”，上限 200KB。不能导入梦境小店存档。

本轮未修改 Download 中的旧版“养石头-硬撑.html”，也未修改梦境小店。浏览器清理数据可能丢档，重要进度请导出。

## 当前边界

这是可继续打磨的第一版立体工程，不是全设备验收完成版。没有惯性旋转、缩放、模型编辑或自动 WebGL 上下文恢复。Three 经典构建会输出弃用提示；当前使用本地固定版本以兼容非模块入口。WebGL 不可用时显示文字提示，下方玩法按钮可继续使用。

## 视觉与交互增强版
- 日志默认最近5条，可展开；确认清空仅删除日志，底层仍最多40条。没有加入全进度重置。
- 灰褐、偏扁不对称程序石头，平滑表面与微弱斑驳；暖灰椭圆地面。
- 相机视向轴四元数增量旋转，支持上下完整翻转，转回来恢复初始方向；翻转时按最低顶点抬升，避免穿地。
- 连摸4次/2.2秒出现水滴；大幅旋转触发怒气或眩晕，漫画反馈8秒冷却。闲置35秒出现Zzz，摸醒有专属台词，不影响任何数值。朋友偶尔出现省略号（尚未加入朋友转头对视动画）。
- 朋友面板含小圆石、瘦高石、扁石，最多同时2位，支持收起。friend保留历史结交语义，新增friends记录当前在场者；旧friend=true存档自动迁移为小圆石在场。
- 彩色填充、加粗放大的SVG贴纸按钮；连摸水滴按试玩反馈改为清楚的💧。
- 本轮直接更新多文件工程；旧ZIP为此前文案版备份，没有重新打包。临时预览仍需本地测试服务，未公开部署。
